# Warframe Tracker

Tracker per Warframe: collezione, maestria e Fonderia. Legge il gioco solo con il riconoscimento del testo sugli screenshot.

## Download

Apri **Releases** e scarica `WarframeTracker_<versione>.zip`.

## Note

- Windows 10 o 11 a 64 bit, con Warframe in inglese.
- L'exe non ha una firma digitale: Windows SmartScreen può mostrare un avviso.
- Il codice sorgente non è pubblico. Tutti i diritti riservati.

Progetto non ufficiale, non affiliato a Digital Extremes. Warframe è un marchio di Digital Extremes.
